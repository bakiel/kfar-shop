Section 02 / Features

Seamless Section Flow

No hard breaks between sections. Gradient bridges, wave dividers, and shared orbs.

Gradient Bridges

Background color transitions smoothly between sections using linear gradients. The eye never hits a hard line.

Wave Dividers

SVG wave paths create organic section boundaries. Configurable amplitude, frequency, and fill color.

Shared Orbs

Color orbs bleed across section boundaries. One orb placed at the seam ties both sections together visually.

Overlapping Sections

Negative margins let sections slide over each other. Combined with gradient masks for depth layering.

Noise Continuity

The same SVG noise texture spans all sections at consistent opacity. Unifies disparate backgrounds into one surface.

Performance Budget

Max 3 backdrop-filter elements visible. Blur capped at 24px. Orbs reduced on mobile. 60fps guaranteed.
