Email & Notifications
05 / 08

Email System

KFAR runs its own email server on the VPS using Postfix and Dovecot. All transactional emails are sent from noreply@kfarapp.com with DKIM signing for deliverability.

Email Accounts

Address Purpose Access
noreply@kfarapp.com Transactional emails (orders, notifications) System only (Postfix)
admin@kfarapp.com Admin contact, support inbox Roundcube webmail
support@kfarapp.com Customer support queries Roundcube webmail

Email Infrastructure

Sending (Postfix)

Mail transfer agent on VPS. SMTP on port 25 (local delivery). Handles all outbound email.

DKIM Signing

All emails digitally signed with DKIM key for deliverability and spam prevention.

Receiving (Dovecot)

IMAP server for receiving and storing emails. Port 993 (SSL encrypted).

DNS Authentication

MX, SPF, DKIM, and DMARC records configured on Hostinger DNS.

Notification Channels

W

Admin Broadcast: Send notifications to all users via POST /api/admin/notifications/broadcast. Supports in-app and email channels simultaneously. Fire-and-forget pattern ensures emails never block the HTTP response.

Deployment & Maintenance

Application runs on a Hostinger VPS with PM2 process management and Nginx reverse proxy.

Server Architecture

User Browserkfarapp.com
→
NginxSSL + Cache + Gzip
→
Next.js AppPort 3006
→
PostgreSQLIndexed queries

Performance: Nginx gzip (87% size reduction), static asset caching (365 days for JS/CSS, 30 days for images), rate limiting on auth endpoints (5 req/sec), security headers (HSTS, X-Frame-Options, CSP). DB queries indexed on vendor_id and created_at.

Common Maintenance Commands

Task Command (run on VPS via SSH)
SSH to server ssh root@<server-host>
View app status pm2 status
View app logs pm2 logs kfar --lines 50
Restart app pm2 restart kfar
Deploy update cd /opt/kfar && git pull && npm install --legacy-peer-deps && NODE_OPTIONS='--max-old-space-size=2048' node_modules/.bin/next build && pm2 restart kfar
Check Nginx nginx -t && systemctl reload nginx
Access database sudo -u postgres psql kfar_marketplace
Check email logs journalctl -u postfix -n 50
Renew SSL certbot renew

Build: Always use NODE_OPTIONS='--max-old-space-size=2048' node_modules/.bin/next build (not npx). VPS builds take ~8.5 minutes. Kill stale node processes first: killall node
