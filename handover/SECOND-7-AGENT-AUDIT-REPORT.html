What the Critical JWT Fix Means

The gap between ecosystem.config.js having strong secrets and the live process using weak ones is a common PM2 pitfall. The correct deploy sequence going forward:

# WRONG — preserves old environment in running process pm2 restart kfar # CORRECT — reinjects environment variables from ecosystem.config.js pm2 reload ecosystem.config.js --update-env # Verify the secret is active pm2 env kfar | grep JWT_SECRET # Should show: JWT_SECRET: f188d148e3181c7c2946e0d81509f7a9e9b289a0d5a5aac8716cf2cdf9c93629

Payment Routes Now Operational

Both YPAY payment routes were completely broken (500 on every call) due to column name mismatch. The orders table uses total (set during DB schema creation), but the payment routes were coded with total_amount. All three references updated:

-- Before (broken) INSERT INTO orders (... total_amount, ...) VALUES (...) SELECT total_amount, ... FROM orders WHERE id = $1 -- After (fixed) INSERT INTO orders (... total, ...) VALUES (...) SELECT total, ... FROM orders WHERE id = $1
